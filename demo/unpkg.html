Guarded definition helper and overrun

This page loads the guarded definition helper from unpkg. The field allows overrun and receives aria-invalid="true" above its limit. Remaining and over-limit text, bold type, and a double field boundary supplement native semantics. Without JavaScript or if the CDN fails, the labeled field, visible limit, and native maxlength enforcement remain. 

<label for="unpkg-message">Message</label>
<textarea id="unpkg-message" maxlength="30"
  aria-describedby="unpkg-help"></textarea>
<small id="unpkg-help">Up to 30 characters.</small>
<form-maxlength-progress for="unpkg-message" overrun="true">
</form-maxlength-progress>

import { defineFormMaxlengthProgress } from
