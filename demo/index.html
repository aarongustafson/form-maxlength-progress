<form-maxlength-progress>

Indicates a user’s progress toward the limit of a field’s maxlength value. See the README for complete API documentation.

The labeled fields, visible limits, and native maxlength enforcement work without JavaScript or if the module fails to load. After upgrade, the counter adds remaining or over-limit text. Dotted underlining marks approaching limits; bold text marks reached or exceeded limits. Only the overrun examples relax native enforcement.

Default counter

The description template supplies both the empty-field text and a native-hidden static description associated through aria-describedby. The changing generated counter is hidden from assistive technology to avoid duplicate and per-keystroke description announcements. The generated [data-form-maxlength-progress-generated-counter] element remains in Light DOM as a supported styling hook. 

<label for="message">Message</label>
<textarea id="message" maxlength="120"
  aria-describedby="message-help"></textarea>
<small id="message-help">Up to 120 characters.</small>
<form-maxlength-progress
  for="message"
  description="Write up to {maxlength} characters"
>
</form-maxlength-progress>
Up to 120 characters.

Paste and autofill checks

These fields exercise real browser input paths rather than buttons that imitate them. Copy the sample into the first field. Use saved address data in the second field to check browser autofill. 

<label for="paste-check">Paste check</label>
<textarea id="paste-check" maxlength="40"
  aria-describedby="paste-help"></textarea>
<small id="paste-help">Up to 40 characters.</small>
<form-maxlength-progress
  for="paste-check" overrun="true"
></form-maxlength-progress>

<form action="./index.html" method="get" autocomplete="on">
  <label for="address-check">Street address</label>
  <input id="address-check" name="street-address"
    autocomplete="street-address" maxlength="40"
    aria-describedby="address-help" />
  <small id="address-help">Up to 40 characters.</small>
  <form-maxlength-progress for="address-check">
  </form-maxlength-progress>

</form>

Authored counter and progress

The host references unique Light DOM descendants using counter and progress. 

<label for="summary">Summary</label>
<input id="summary" maxlength="80"
  aria-describedby="summary-help" />
<small id="summary-help">Up to 80 characters.</small>
<form-maxlength-progress class="custom-progress"
  for="summary"
  counter="summary-count"
  progress="summary-meter"
  proximity-values="safe 0%, warning 60%, target 100%"
>
  <span><strong id="summary-count"></strong> left</span>
  <progress id="summary-meter"></progress>
</form-maxlength-progress>
Up to 80 characters. The native progress bar supplements the remaining count. left

French translation and overrun

The component inherits lang for plural selection. Translate the description, remaining and overrun labels, and reached/exceeded alerts together. Overrun removes native enforcement and sets aria-invalid="true" until the value returns within the limit. This warm theme pairs its reading, field, boundary, and focus colors. Forced colors restore the system pairs. 

<div class="custom-theme" lang="fr">
  <label for="short-note">Note courte</label>
  <textarea id="short-note" maxlength="40"
    aria-describedby="short-note-help"></textarea>
  <small id="short-note-help">40 caractères maximum.</small>
  <form-maxlength-progress
    for="short-note"
    overrun="true"
    description="{maxlength} caractères maximum"
    label="{remaining} caractères restants"
    label-one="{remaining} caractère restant"
    overrun-label="{remaining} caractères en trop"
    overrun-label-one="{remaining} caractère en trop"
    limit-reached-label="Limite de caractères atteinte"
    limit-exceeded-label="Limite de caractères dépassée"
  ></form-maxlength-progress>
</div>
40 caractères maximum. Après activation, le dépassement est signalé, mais reste possible.

Event handling

Listen for form-maxlength-progress:notification to respond when the field nears, reaches, or exceeds its limit. The event’s detail includes its milestone state, message, priority, remaining count, maximum, and associated field. 

<label for="event-message">Notification event</label>
<textarea id="event-message" maxlength="20"
  aria-describedby="event-help"></textarea>
<small id="event-help">Up to 20 characters.</small>
<form-maxlength-progress id="event-progress"
  for="event-message" overrun="true">
</form-maxlength-progress>

document
  .querySelector('#event-progress')
  .addEventListener(
    'form-maxlength-progress:notification',
    (event) => {
      console.log(event.detail);
    }
  );
Up to 20 characters. With enhancement, extra text is allowed and marked invalid.
